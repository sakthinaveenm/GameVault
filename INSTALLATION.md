# Installation Guide

## System Requirements

- **Operating System**: macOS 12+ (Apple Silicon or Intel), Windows 10/11, Ubuntu 22.04+ / Arch Linux / Fedora
- **RAM**: Minimum 512 MB available, Recommended 1 GB
- **Disk Space**: ~150 MB for the base application launcher
- **Peripherals**: Xbox Series / One, PlayStation DualSense / DualShock 4, Nintendo Switch Pro, or generic XInput controller; Mouse & Keyboard supported.

## Binary Installation

### macOS
Download `UniversalGameHub.dmg`, open it, and drag `Universal Game Hub.app` to your Applications folder.

### Windows
Download and execute `UniversalGameHub-Setup.exe` (or use the portable `.zip` release).

### Linux
Download the `UniversalGameHub.AppImage` and mark it executable:
```bash
chmod +x UniversalGameHub.AppImage
./UniversalGameHub.AppImage
```
Or install via Debian package:
```bash
sudo dpkg -i universal-game-hub.deb
```
